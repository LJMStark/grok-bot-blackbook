## 🎯 适合谁

- **完全没用过 Grok Bot 的新手**：想知道它是什么、国内怎么开通、第一个任务怎么派。
- **已经在用、但总觉得没用明白的人**：Bot、云电脑、Skill、Routine、Pages/Canvas、审批、连接器到底怎么配合。
- **想让 AI 干正事的个人、创作者和小团队**：内容工作室、研发流水线、总助 Bot、多 Bot 群聊协作与 BDK 跨端自动化。
- **被额度、故障、封号、骗局困扰的人**：The X Subscription 档位对比、省钱心法、事故档案、故障速查、反模式。

## 📦 书里有什么

- **9 个 Part、前言 + 24 章正文 + 附录 A–J**：起步 → 核心概念 → 扩展与集成 → 多 Bot 协作 → 热门用例 → 完整落地项目 → 省钱 → 避坑与事故 → 心智模型。全书约 20 万纯汉字（67.2 万总字符），PDF 全书共 **358 页**。
- **2026 年 10 月（至 v0.75.5）核心特性全覆盖**：The X Subscription 订阅重构（$10/$16/$100 档位）、Pages/Canvas 交互式报告与仪表盘、1Password Brokered Sign-in 代理登录、Grok Bot Vault 加密凭证保险库、iPhone Action Button v1.16 一键语音唤醒、Grok Imagine 视频生成与代码动效引擎、BDK 跨客户端直连调用协议、`@chat` 端到端加密私信、专属邮箱 `+alias` 别名秒级事件触发、Routine 300 总数 / 200 启用上限，以及 40+ 个 X 社区最新高阶实战案例。
- **中国用户专章**：支付宝开通路径、手机号验证、网络、代充与骗局识别、没有插件时怎么接微信、小红书、B 站和飞书。
- **两个完整落地项目**：从零搭“中文内容工作室”；Bot + Cursor 云端 Agent + GitHub 研发场景。
- **61 张图解 + 封面**、**36 套可复制提示词与 Routine 模板集**、连接器清单、版本更新时间线（覆盖至 v0.75.5）、FAQ 20 问、术语表、来源总表与勘误页。
- **[📚 精选资料库（224 条）](resources/README.md)**：共 224 条，分 8 大类整理官方资料、教程、玩法、行业案例、精选帖子、模板和踩坑记录，awesome 清单风格，开箱即查。
