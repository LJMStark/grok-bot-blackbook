## 🎯 适合谁

- **完全没用过 Grok Bot 的新手**：想知道它是什么、国内怎么开通、第一个任务怎么派。
- **已经在用、但总觉得没用明白的人**：Bot、云电脑、Skill、Routine、审批、连接器到底怎么配合。
- **想让 AI 干正事的个人、创作者和小团队**：内容工作室、研发流水线、总助 Bot、多 Bot 群聊协作。
- **被额度、故障、封号、骗局困扰的人**：省钱心法、事故档案、故障速查、反模式。

## 📦 书里有什么

- **9 个 Part、前言 + 24 章正文 + 附录 A–J**：起步 → 核心概念 → 扩展与集成 → 多 Bot 协作 → 热门用例 → 完整落地项目 → 省钱 → 避坑与事故 → 心智模型。
- **中国用户专章**：支付宝开通路径、手机号验证、网络、代充与骗局识别、没有插件时怎么接微信和飞书。
- **两个完整落地项目**：从零搭"中文内容工作室"；Bot + Cursor 云端 Agent + GitHub 研发场景。
- **61 张图解 + 封面**、提示词与 Routine 模板集、连接器清单、版本更新时间线、FAQ 20 问、术语表、来源总表与勘误页。
- **[📚 精选资料库](resources/README.md)**：134 条官方资料、教程、玩法、行业案例、精选帖子、模板和踩坑记录，awesome 清单风格，按类别整理。
